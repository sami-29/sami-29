# Sami Bentaleb
**`Full-stack developer`** · Annaba, Algeria (UTC+1) · open to full-time and contract work, remote

Hey, I'm Sami. I build web apps end to end, mostly in TypeScript, with Rust and Go when the job calls for it. Lately that's been a prescription-parsing pipeline for SmartSig, the API behind 2SCL's SDG indicator platform, and an operations board for an optical lab in Toronto. That client work is private, so here's what you can poke at:

- [Tetris Lab](https://github.com/sami-29/tetris-lab): I taught a computer to play Tetris. A Rust beam search compiled to WebAssembly, running in your browser at [lab.samibentaleb.com](https://lab.samibentaleb.com).
- [Speeedy](https://github.com/sami-29/speeedy): a free, local-first speed reader for PDFs and EPUBs.
